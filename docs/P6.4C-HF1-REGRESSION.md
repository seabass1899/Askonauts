# ASKONAUTS P6.4C-HF1 — Cross-World Stabilization

Baseline: P6.4C shared-shell build.

This hotfix intentionally adds no new world content and no visual makeover work. It stabilizes the shared application shell before the presentation pass.

## Stabilization changes

- Centralized Escape behavior in `GlobalGameUI`.
  - Escape closes Settings, Journal, or Question Tree first.
  - If no modal is open, Escape returns to the Clubhouse in world scenes.
  - In the Clubhouse, Escape only closes an open shared modal.
- Removed duplicate scene-level Escape handlers from Shadow Chase, Reflection Lab, Spoon Lab, and Funhouse Mirrors.
- Enforced one shared overlay at a time. Opening Journal, Tree, or Settings closes the other shared overlays first.
- Added explicit open-state checks to Question Tree and Settings overlays.
- Added shared-overlay teardown on scene shutdown.
- Added `PrototypeAudio.destroy()` and wired it into `AudioManager.destroy()` so Web Audio contexts are closed during scene transitions instead of accumulating across worlds.
- Preserved one authoritative `VoiceDirector` through `AudioManager` in every primary scene.
- Updated visible build markers to P6.4C-HF1 where the current UI exposes a version marker.

## Source-level verification

- 5/5 primary scenes instantiate `GlobalGameUI`.
- 5/5 primary scenes instantiate `AudioManager`.
- 0 primary scenes instantiate `VoiceDirector` directly.
- 0 world scenes own a separate Escape-to-Clubhouse keyboard handler.
- TypeScript: `tsc --noEmit` passes against the project dependencies.
- Vite bundle cannot be verified in the Linux packaging environment because the existing dependency tree lacks Rollup's Linux native optional package. Run `npm install` on the target machine before `npm run build`.

## Manual regression sequence

Run this sequence in every world before accepting HF1:

1. Open Journal; press Escape; confirm the Journal closes and gameplay remains in the same world.
2. Open Tree; press Escape; confirm the Tree closes and gameplay remains in the same world.
3. Open Settings; press Escape; confirm Settings closes and gameplay remains in the same world.
4. With no modal open, press Escape; confirm world scenes return to the Clubhouse.
5. Toggle master audio off/on and verify the header icon follows state.
6. Change audio from Settings and verify the header icon follows state.
7. Move between worlds repeatedly and confirm narration/SFX continue to work without browser audio-context failures.
8. Open Journal and replay a collected discovery; confirm routing returns to the correct world.
9. Open Question Tree and revisit an available/completed world; confirm routing is correct.
10. Confirm Sparks, discoveries, secrets, world completion, and unlocks survive scene transitions and browser refresh.
11. Complete each world's core experiment/mission and confirm its completion CTA still returns to the Clubhouse.
12. Confirm Spoon Lab manipulation controls still work exactly as in P6.4B-HF1.
